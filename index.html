02how a hook works

The token calls your rule. Every single time.

Solana's Token-2022 program has an extension called a transfer hook. When a mint has one, every transfer calls a small program before it can complete. If that program says no, the whole transaction fails.

  1. Aa wallet moves the coin
  2. BToken-2022 sees the hook
  3. Cthe hook reads your rule
  4. Dit lands, or it reverts
max_buy.rsthe shape of a hook · simplified
// called by Token-2022 on every transfer of the coin
pub fn execute(ctx: Context<Execute>, amount: u64) -> Result<()> {
    let rule = &ctx.accounts.rule;                     // set once at launch
    let now  = Clock::get()?.unix_timestamp;
    if now < rule.launched_at + rule.window {           // first 10 minutes
        let cap = rule.supply * rule.max_bps / 10_000;  // 1% of supply
        require!(amount <= cap, HookError::OverMaxBuy);  // over it: the transfer reverts
    }
    Ok(())                                               // inside it: it lands
}
A · THE TRANSFER

A wallet moves the coin

A buy from the pool, a sell into it, a send to a friend. Underneath it is the same transfer instruction, and that is what the hook sees.

B · THE TOKEN PROGRAM

Token-2022 sees the hook on the mint

The mint names a hook program. Token-2022 calls it on every transfer, passing the sender, the receiver, the amount and any extra accounts the rule needs.

C · THE RULE

The hook reads your rule

The rule was written at launch: the cap, the window, the sunset. The hook compares this transfer against it, using the clock and the balances it was handed.

D · THE OUTCOME

It lands, or nothing moves

Inside the rule, the transfer completes. Outside it, the hook returns an error and the whole transaction reverts. No dev has to be awake for that.

      07questions and risks
      
      
      Straight answers.
      
      
      What a hook is, what it can't do, and what you should check before you buy any token that has one.
      
    
      
    
      
      
      
        
      What is a transfer hook?
      An extension of Solana's Token-2022 program. A mint can name a hook program, and every transfer of that token calls it. The hook can check the transfer and make it fail. That is the whole mechanism hooked is built on.
      
        
      Can a rule stop me from selling?
      Not on hooked. The library only has rules that limit buying, wallet size, buy speed and the creator's own tokens, and every rule has a sunset after which the coin is a plain token. A hook that can block ordinary sells is a honeypot, and the inspector flags tokens whose hooks you can't read.
      
        
      Where do hooked coins trade?
      Only on venues that support Token-2022 transfer hooks. Many Solana swaps and launchpads don't, which is why a hooked coin can't simply launch on every pad. Each launch will list the venues that accept it before you pay.
      
        
      Can the creator change the rule later?
      No. The rule is written at launch and the hook program will be made immutable, so nobody can swap in a different rule afterwards. The sunset date is part of the rule.
      
        
      What does the inspector read?
      The mint account itself, from Solana mainnet: the token program, every Token-2022 extension and its settings, the mint and freeze authorities, and the supply. Names and pictures come from Jupiter's token list.
      
        
      When do launches open?
      With $HOOKED. Until then the inspector is live and the launch page shows exactly what will be written, without creating or sending anything.
